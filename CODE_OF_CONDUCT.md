# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every project space: issues, pull requests,
discussions and any event held for the project.

Report unacceptable behaviour privately to **security@stellersight.com (subject "Conduct")**. The
maintainers will review every report, respond, and keep the reporter's
identity confidential. Enforcement follows the Contributor Covenant's
enforcement guidelines.
